🤫 Tact playground

Tact is a Strands agent whose long-term memory passes through Strands Decider 2B. For each remembered fact, the decider gives three probabilities; a small cost table then decides whether the agent may mention it, uses it quietly, or skips it. This page replays the decider's real answers from Tact's evaluation and runs that cost table in your browser. Change it and see what the agent would do.

How bad is saying something painful?

The cost of mentioning a fact that should have stayed quiet. Tact ships with 3: three times worse than holding back a useful fact. The policy picks the action with the lowest expected cost under the decider's probabilities.
